# Pairs-trading-Backtester
This is a program designed to analyse data from a training period of 2 correlated stocks, to see whther there is a profitable pairs trading strategy.
It produces heat maps of 'profit/loss', 'annualised sharpe ratio', 'winrate', 'max drawdown', 'profit factor',  and 'number of trades', for various signal combinations.
It also has a function to test the strategy on 'out-of-sample' data, using signal parameters chosen by the user from the heatmaps.
